# Roadmap

This roadmap describes the direction for the open V4 codebase. It is not a promise that every item will land in the exact order shown.

## V4.1 — investigation fundamentals

- Complete evidence capture workflow.
- Add screenshot evidence support.
- Add investigation notes/editing.
- Add JSON and CSV exports.
- Improve tool diagnostics and provider tests.
- Expand automated test coverage.

## V4.2 — visualisation and reporting

- Add HTML/PDF exports.
- Add file/image upload investigations.
- Add map workspace.
- Add relationship graph.
- Improve activity/timeline presentation.

## V4.3 — tool management

- Install optional tools from the application.
- Repair/update tool integrations.
- Enable/disable integrations.
- Allow controlled user-imported tools with inspection and diagnostics.
- Improve permissions and command execution controls.

## Future

- More robust resource modes.
- Installer/setup wizard.
- Plugin/provider architecture.
- Optional AI assistant integration, potentially including Ollama or compatible local/cloud gateways.
- Stronger cross-platform support where practical.

Contributors are encouraged to turn roadmap items into small, testable GitHub issues rather than implementing several unrelated features in one pull request.
