# Code of Conduct

## Our standard

WireSploit contributors should treat each other with respect and keep technical discussions constructive.

Expected behaviour includes:

- Being respectful of different experience levels.
- Giving useful technical feedback without personal attacks.
- Explaining disagreements with evidence and reasoning.
- Respecting privacy and not sharing another person's private information.
- Keeping issue and pull-request discussions focused on improving the project.

Unacceptable behaviour includes harassment, threats, discrimination, deliberate disclosure of private information, and disruptive personal attacks.

Project maintainers may remove comments, close discussions or restrict participation when behaviour prevents constructive collaboration.

## Scope

This applies to project spaces including GitHub issues, pull requests, discussions and other project-controlled collaboration spaces.
